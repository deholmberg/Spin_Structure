# Spin Structure Overview

This directory contains all the analysis code that's used in the proton longitudinal spin structure analysis. This directory contains all the scripts I used to parse the 
CLAS12 HIPO-format data files, write data to tree objects, and then further parse into data that can be used to calculate all relevant quantities. The goal is to create
a repository/guide so that any poor sucker who has to sift through my bullcrap can have a slightly less painful time trying to figure out what I actually did lol.
